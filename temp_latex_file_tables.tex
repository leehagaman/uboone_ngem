\section{Technical Details}
\label{sec:technical_details}

This section describes more technical details of the analysis.

\subsection{Samples Used}

The samples in this analysis were produced by the production team. The generation through Reco 1 stages use MCC9, while the Reco 1 through ntuple stages use MCC10 (this is also called the MCC9.10 or SURPRISE workflow). The resulting ntuples are referred to as SURPRISE files.

These output SURPRISE ntuples then undergo spline reweighting, processed using MCC9 on the grid, in order to add additional flux and cross section weights to be used for systematic understanding using PROfit \cite{profit}. This processing step operates only on the ntuples, making the computational cost minimal relative to the other simulation and reconstruction steps.

Then, the samples undergo Wire-Cell postprocessing \cite{wc_postprocessing}, which does several things:

\begin{itemize}
    \item Calculates and adds the $\nu_\mu$CC, $\nu_e$CC, NC $\pi^0$, and NC $\Delta\rightarrow N \gamma$ Wire-Cell BDT scores.
    \item Cuts to the good runs list
    \item Removes subruns where the LANTERN reconstruction container failed
    \item Separates subruns used to train Wire-Cell BDTs into different files (not used in this analysis)
    \item Removes duplicate subruns
    \item Removes events that have corrupt or missing Wire-Cell information
    \item Re-scales invalid or extreme outlier GENIE cross section weight values
\end{itemize}

\begin{sloppypar}
POT values for these files are tracked for simulated neutrino files by summing \texttt{wcpselection/T\_pot/pot\_tor875good} in each file. For data (beam-on) and EXT (beam-off) files, we calculate the POT values by using Zarko's tool \texttt{/exp/uboone/app/users/zarko/getDataInfo.py -v3} while passing in a list of run-subrun pairs. For data files, we use the \texttt{tor875\_wcut} value for the POT. For EXT files, we use the corresponding data period's POT weighted by the EXT file's number of triggers \texttt{EXT} divided by the data file's number of triggers \texttt{E1DCNT\_wcut}. This process is described at \url{https://github.com/leehagaman/uboone_ngem/blob/main/ipynb_notebooks/pot_and_trigger_processing.ipynb}.
\end{sloppypar}

NuWro fake data files are also analyzed, in this case with no EXT or dirt simulation included. For these, the flux and detector effects are identical between the prediction and fake data, and only the cross section and statistical fluctuations cause the observed variations.

Tables~\ref{tab:data_ext_samples}, \ref{tab:fake_data_samples}, \ref{tab:mc_samples}, and \ref{tab:detvar_samples} list the data, EXT, NuWro fake data, Monte Carlo, and detector variation samples used in this analysis, organized by file type and run period.
